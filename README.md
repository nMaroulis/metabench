# BenchIndex – Metacritic for LLMs

## Project Overview:

BenchIndex is a full-stack web platform that aggregates and normalizes LLM benchmark results from multiple sources (MMLU, GSM8K, HumanEval, BigBench, HuggingFace leaderboards, TypeThink, Vellum, and community submissions). It produces a single “Overall Intelligence Score” for each model while maintaining per-task breakdowns, multi-language support, cost, and latency metrics. Users can explore leaderboards, compare models, and download data via API.
